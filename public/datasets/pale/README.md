## Requisitos

- Formato JPEG o PNG
- Fondo limpio o neutro (mejora la consistencia del producto generado)
- Resolución mínima recomendada: 800×800 px

Sin estas imágenes, `/api/task1/generate` genera igual pero sin garantía de
consistencia visual del producto.
